# 技术架构 SVG

本图按六层职责视图展示当前系统，不表示代码目录已重构。Bootstrap 省略；核心能力位于系统内部，外部模型与本机工具执行边界单独展示。

- 可编辑源图：`layered-architecture-v3.svg`
- 浏览器渲染预览：`layered-architecture-v3.png`
- 生成脚本：`scripts/render_architecture.py`；直接运行会重新生成 SVG。手工修改 SVG 后，不应运行脚本覆盖这些修改，应将修改同步到脚本。

主要连接：微信 → 接收渠道 → 消息处理 → Turn 队列 → 任务调度 → Outbox → 回复投递 → 发送渠道 → 微信。消息处理关联会话，任务调度按需控制会话并调用 Agent Runtime；会话结束触发记忆整理。权限与工具管理连接本机沙箱。

领域层展示模型与规则归属，不是必须经过的请求中转层。各模块通过接口使用基础设施；Admin 查询包含业务状态和 Trace，图中聚合至观测入口。记忆生成也复用模型能力，图中省略该辅助连线。typing 等辅助 Channel 交互省略。

实线：主要业务流。虚线：能力调用或查询。Turn / Outbox 表示持久队列交接，并非直接函数调用。执行 / 结果使用单个调用箭头概括请求与返回。

层间关系：核心能力层指向领域层，表示使用领域模型与规则；应用编排层与核心能力层通过左侧公共访问线指向基础设施层，表示通过接口读写与记录。公共访问线实心圆表示连接点，不经过领域模型卡片，也不表示领域层直接访问存储。

历史 PNG 与图像生成草图保留，不作为当前图的准确连线依据。
